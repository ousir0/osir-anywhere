# OSIR Client 本机模型交接 v1

此文件只在同一系统用户的本机使用，不是 Server API、身份授权或目录授权。正式生产者为 OSIR Client 原生服务，写入其设备目录 `anywhere/codex-binding.json`；开发身份使用隔离设备目录。接收端固定选择本机路径，云端不能指定路径、Home、可执行文件或凭据。

合同见 `contracts/osir-local-model-binding/v1/schema.json`。生产者每 10 秒续写 30 秒有效期。Unix 使用文件 0600、目录 0700、原子替换并拒绝符号链接；Windows 使用原生所有者、DACL 与重解析点检查，不能把 chmod 的结果当作 Windows 权限验证。模型仅来自当前已发布供应商及模型，不能从历史目录整体复制。默认模型必须包含在清单内。不可用、待提交配置、代理未运行时发布 `available:false` 和固定错误码。

接收端验证当前系统用户、文件权限、有效期、精确 Home、配置与目录内容摘要，并将 revision 固定到本次 Runtime 生命周期。每次模型读取及新的模型写操作复核；revision 或文件摘要改变时拒绝旧运行时的新请求，提示重新连接。进行中的输出不强行中断。模型切换通过重新连接受管 Runtime 生效，不重启用户其他客户端。

`models`、`defaultModel` 可以转换成现有云端公开模型目录；Home、文件摘要、expiry、完整描述符、模型密钥及账号凭据不得上传。身份仍由现有独立 OSIR 授权管理，项目仍由本机已批准范围管理。此合同不授权复制 Key、读取 Client 数据库或扩大历史同步范围。

本轮首批覆盖 Codex。Claude 等运行时没有对应本机绑定前不能宣称与 OSIR 当前配置已统一。

## 正常产品接线与首版范围

OSIR Desktop 的正常启动链必须由固定产品身份选择受绑定的 Codex Provider，不能依赖开发菜单、测试项目桥或本机源码路径。绑定路径与用户 home 来自本机启动层；远端 Runtime 配置不能关闭绑定或改用其他 home、模型网关、环境路由及任意可执行文件。普通上游产品保留原 Provider。

受绑定的 SDK 会话在启动、列模型、会话读写、模型设置、缓存与状态返回、后台发布等边界复核。模型、路由或授权描述符改变后，旧运行时报告不可用；重新连接创建新的绑定实例与目录代次。停止本实例及中止自有请求仍可用于清理，不因绑定失效而失去关闭能力。

首版受绑定路径关闭尚未完成绑定验证的跨进程 Codex IPC、外部桌面接管与外部控制；正常 SDK 会话为本期支持路径。这不扩大项目授权或历史同步范围，也不代表对同用户任意代码及终端命令提供文件沙箱。

截至 2026-11-14，正常产品接线与平台 reader 已完成源码实施及定向回归；ARM 上真实 SDK/内置 CLI 0.167.2 的合成本地路由探针通过，新建及进程重连请求均走绑定地址。该探针没有真实模型回复，Windows 原生配对、真实 Client 生产者、最终安装包和真实模型端到端仍需分别验收。旧 r2 安装包退出最终候选，不能继承给新 r3；实际状态见发布实施记录及各项原始回执。
